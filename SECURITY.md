# Security

## Reporting a vulnerability

Report it privately, by
[Report a vulnerability](https://github.com/wardawgmalvicious/neith-releases/security/advisories/new)
on this repository's **Security** tab, not in Q&A or anywhere public.

In scope are the installer, the update feed (each release's
`latest.json` and the setup.exe's `.sig`) and the Neith app.

## Supported versions

Only the latest release gets fixes. An installed copy offers each new
release when it starts.
